## 🔧 How It Works

### Local Development (Current)
```
User clicks "Scan Card" 
  → Browser calls PHP API: SensorServerClient.php?action=scan
    → PHP calls Python server at localhost:8765
      → Python server triggers Arduino RFID scan
        → Result sent to database
          → Response returned to browser
```

### Online Production
```
User clicks "Scan Card" on unilis.jhubafrica.com
  → Browser calls PHP API: SensorServerClient.php?action=scan
    → PHP calls Python server at 127.0.0.1:8765
      → Python server triggers Arduino RFID scan (connected via USB)
        → Result saved to production MySQL database
          → Response returned to browser
```

## 📊 Database Schema

### rfid_scans table
```sql
id            INT AUTO_INCREMENT PRIMARY KEY
uid           VARCHAR(50) NOT NULL UNIQUE      -- RFID card UID
scan_time     VARCHAR(8)                       -- HH:MM:SS
created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
```

### co2_readings table
```sql
id            INT AUTO_INCREMENT PRIMARY KEY
ppm           INT NOT NULL                     -- CO2 level
status        VARCHAR(50)                      -- Excellent/Good/Fair/Poor
color         VARCHAR(10)                      -- Hex color for status
bg            VARCHAR(10)                      -- Background color
reading_time  VARCHAR(8)                       -- HH:MM:SS
created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
```

## 🚀 Quick Deployment Checklist

- [ ] Review all new files (they're well-commented)
- [ ] Test locally: `python smart-lab/web-app/smart-lab-server-production.py`
- [ ] Create production database: `mysql < database_setup/rfid_co2_production.sql`
- [ ] Copy files to server via SCP/SFTP
- [ ] Create `.env.production` on server with correct credentials
- [ ] Install Python dependencies: `pip install -r requirements.txt`
- [ ] Enable systemd service: `sudo systemctl enable smart-lab-sensor`
- [ ] Start service: `sudo systemctl start smart-lab-sensor`
- [ ] Verify: `curl http://localhost:8765/health`
- [ ] Monitor: `sudo journalctl -u smart-lab-sensor -f`

### For unilis.jhubafrica.com:
Your `.env.production` should have:
```env
SMART_LAB_SERIAL_PORT=/dev/ttyUSB0       # Linux USB port
SMART_LAB_BAUD_RATE=9600

SMART_LAB_DB_HOST=localhost
SMART_LAB_DB_USER=smart_lab_user
SMART_LAB_DB_PASS=[your_password]
```
